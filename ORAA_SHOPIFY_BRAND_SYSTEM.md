# ORAA SHOPIFY --- BRAND SYSTEM

## Source de vérité de marque --- V1 de conception

**Statut :** Spécification structurante pré-implémentation\
**Projet :** ORAA Shopify exclusivement\
**Mission :** garantir que le client retrouve ORAA partout, du Monde
ORAA au post-achat, sans rupture visuelle, éditoriale ou
transactionnelle.

------------------------------------------------------------------------

# 1. Principe central

ORAA doit être reconnaissable sans devoir afficher son logo partout.

> **ORAA crée suffisamment d'identité pour pouvoir laisser de
> l'espace.**

L'harmonisation ne signifie pas uniformisation. Chaque maison peut avoir
une personnalité propre, mais toutes appartiennent à la même ville et
utilisent le même ADN.

Trois questions de contrôle pour chaque décision : 1. Est-ce
immédiatement reconnaissable comme ORAA ? 2. Est-ce que cela renforce la
confiance ? 3. Est-ce que cela facilite plutôt que gêner l'achat ?

------------------------------------------------------------------------

# 2. Rythme de marque

**WAOUH → respiration → découverte → respiration → désir → confiance →
transaction → souvenir.**

Guide d'intensité : - Monde ORAA : 100 % --- émerveillement. - Maison /
collection : \~60 % --- caractère + espace. - Produit : \~30 % --- le
produit domine. - Checkout : \~10 % --- la clarté domine. - Post-achat :
remontée émotionnelle mesurée.

Ce guide n'est pas une règle mathématique.

------------------------------------------------------------------------

# 3. Signature maîtresse

Le système de signature comprend : - mot-marque ORAA ; - anneau ORAA ; -
typographie ; - palette mère ; - lumière ; - traitement
photographique/vidéo ; - formes ; - iconographie ; - motion language ; -
ton rédactionnel ; - composants UI.

Claude Code ne doit pas inventer ces éléments au cas par cas.

------------------------------------------------------------------------

# 4. Anneau ORAA

Référence : - anneau ouvert ; - métal doré ; - profondeur bleu nuit ; -
lumière bleue intense, particulièrement vers le bas ; - sensation de
portail/passage.

Fonctions : - signature ; - passage ; - activation ponctuelle ; -
certains moments émotionnels/post-achat.

À éviter : - omniprésence ; - spinner ; - rotation permanente ; - cercle
doré générique ; - multiplication décorative.

Pour les petits formats, créer une déclinaison dédiée plutôt que
dénaturer la référence.

------------------------------------------------------------------------

# 5. Couleur

Le système doit distinguer :

## 5.1 Palette institutionnelle

Couleurs stables de l'identité ORAA.

Direction validée : - bleu profond / bleu nuit pour certaines signatures
; - or métallique/chaleureux pour la signature ; - environnement
lumineux et naturel pour le Monde ORAA.

Les valeurs hexadécimales définitives doivent être validées à partir des
assets finaux et tests d'accessibilité avant gel.

## 5.2 Monde ORAA

-   ciel bleu ;
-   lumière naturelle ;
-   tons architecturaux crédibles ;
-   végétation ;
-   eau ;
-   rosiers rouges discrets.

## 5.3 Accents des maisons

Une maison peut avoir un accent propre, dans une gamme contrôlée.

## 5.4 Couleurs fonctionnelles

Succès, erreur, alerte, promotion, indisponibilité, focus et CTA doivent
prioriser compréhension et contraste.

Aucune couleur fonctionnelle ne doit être choisie uniquement pour «
faire ORAA » au détriment de l'UX.

------------------------------------------------------------------------

# 6. Typographie

Objectif : identité + lisibilité.

Prévoir au maximum : - une famille identitaire pour grands
titres/moments de marque ; - une famille hautement lisible pour
navigation, commerce, produit, formulaires et transaction ; - troisième
usage exceptionnel uniquement si justifié.

Les familles exactes restent à valider.

Exigences : - excellente lecture mobile ; - chiffres/prix très lisibles
; - accents français complets ; - poids nécessaires ; - performance web
; - licence appropriée.

------------------------------------------------------------------------

# 7. Lumière ORAA

La lumière est un code de marque.

Caractéristiques : - naturelle ; - cinématographique ; - volumes
lisibles ; - profondeur ; - chaleur maîtrisée ; - jamais uniformément
jaune.

Une future image peut être testée par : **« Est-elle éclairée comme ORAA
? »**

------------------------------------------------------------------------

# 8. Photographie et vidéo

## Monde

Narratif, immersif, cinématographique, merveilleux mais crédible.

## Produit

Réel, précis, utile : - vue générale ; - détails ; - matière ; - échelle
; - utilisation ; - démonstration.

Règle : \> Une publicité peut raconter. Une démonstration doit prouver.

Ne jamais embellir au point de créer une attente trompeuse sur le
produit réel.

------------------------------------------------------------------------

# 9. Formes et langage graphique

L'anneau inspire : - courbe ; - ouverture ; - continuité ; - cadre ; -
passage.

Ces principes peuvent influencer certaines découpes, cadres ou
micro-détails sans reproduire littéralement l'anneau partout.

Éviter une collection de formes décoratives sans fonction.

------------------------------------------------------------------------

# 10. Iconographie

Les icônes doivent être : - cohérentes ; - simples ; - immédiatement
compréhensibles ; - accessibles ; - visuellement compatibles avec ORAA.

Un système principal, pas plusieurs familles mélangées.

Les icônes commerciales standards doivent rester familières lorsque la
convention aide l'utilisateur.

------------------------------------------------------------------------

# 11. Motion Language

Trois mots : **lent --- naturel --- intentionnel.**

Familles : - ambiance : monde vivant ; - réaction : réponse au visiteur
; - passage : changement d'univers ; - commerce : feedback court ; -
produit : calme.

Respect obligatoire de reduced motion.

La capacité technique n'est jamais une justification artistique.

------------------------------------------------------------------------

# 12. Monde ORAA

Le Monde est le moment de marque le plus intense.

Référence détaillée :
`ORAA_SHOPIFY_MONDE_ORAA_MASTER_EXPERIENCE_SPEC.md`

Il comprend notamment : - scène lumineuse/aérienne ; - maisons ; -
enseignes réactives ; - montgolfière ; - avion ; - micro-vie naturelle
; - anneau comme passage ; - respiration ; - accès direct au commerce.

------------------------------------------------------------------------

# 13. Maisons

Chaque maison : - porte extérieurement le nom clair de la collection ; -
peut avoir un nom narratif intérieur ; - possède un mini-univers ; -
partage les composants ORAA ; - adapte son éditorial à sa catégorie.

Maison pilote : `ORAA_SHOPIFY_EXPERIENCE_SYSTEM_MAISON_PILOTE_TECH.md`

Principe : **Même ville. Différentes maisons.**

------------------------------------------------------------------------

# 14. Navigation

La navigation doit rester reconnaissable et stable à travers les
univers.

Elle doit permettre : - retour Monde ORAA ; - collections ; - recherche
; - compte ; - panier ; - accès direct sans immersion obligatoire.

La créativité ne doit jamais masquer les fonctions essentielles.

------------------------------------------------------------------------

# 15. Boutons et CTA

Construire un système limité : - primaire ; - secondaire ; -
tertiaire/texte ; - états hover/focus/active/disabled/loading.

Les CTA commerciaux doivent être extrêmement clairs.

Éviter : - styles différents à chaque maison ; - animations excessives
; - libellés vagues lorsqu'une action précise est possible.

------------------------------------------------------------------------

# 16. Cartes produit

Toutes les cartes doivent appartenir au même système.

Prévoir : - image ; - nom ; - prix ; - prix comparé/promotion si réel
; - variantes essentielles si pertinent ; - avis si réellement
disponibles ; - badges contrôlés ; - états hover/touch ; - CTA selon
stratégie.

Une maison peut adapter son environnement, pas réinventer la carte
produit sans raison.

------------------------------------------------------------------------

# 17. Fiche produit

Le produit domine.

Priorités : - compréhension ; - image ; - bénéfices ; - prix ; -
variantes ; - CTA ; - livraison/retours ; - preuves ; - démonstrations
; - détails.

L'identité ORAA agit par la qualité du système, pas par décoration
excessive.

------------------------------------------------------------------------

# 18. Prix, promotions et avis

Doivent être : - lisibles ; - honnêtes ; - cohérents ; - non
manipulateurs.

Claude Code ne corrige ou n'invente aucun prix/promo de sa propre
initiative.

Les avis ne doivent pas être simulés.

Les promotions ne doivent pas utiliser de faux compteurs ou fausse
urgence.

------------------------------------------------------------------------

# 19. Panier

Le panier marque le passage vers la transaction.

Objectifs : - récapitulatif évident ; - quantités modifiables ; -
suppression claire ; - coûts compréhensibles ; - CTA checkout évident
; - réassurance mesurée.

Réduire fortement les distractions.

------------------------------------------------------------------------

# 20. Checkout

Le checkout doit être le moment le plus calme.

Priorité : **confiance + clarté + vitesse.**

Appliquer ORAA dans les limites techniques et réglementaires de Shopify
: - logo ; - couleurs compatibles ; - typographie si supportée ; -
microcopy autorisée ; - cohérence visuelle.

Ne jamais sacrifier les conventions de paiement à une expérience
immersive.

------------------------------------------------------------------------

# 21. Confirmation et post-achat

Après le paiement, ORAA peut remonter légèrement en émotion.

Points de contact : - confirmation ; - e-mail ; - suivi ; - compte ; -
SAV ; - demande d'avis ; - packaging ; - QR éventuel ; - expérience de
réception.

Le dernier « waouh » peut arriver après l'achat.

------------------------------------------------------------------------

# 22. E-mails et SMS transactionnels

Même ADN : - logo/signature ; - typographie compatible ; - hiérarchie
; - ton ; - CTA ; - informations pratiques.

La lisibilité et la délivrabilité priment sur le décor.

------------------------------------------------------------------------

# 23. Ton rédactionnel

ORAA doit être : - clair ; - accueillant ; - élégant ; - humain ; -
jamais prétentieux ; - jamais artificiellement mystérieux lorsque le
client a besoin d'une information simple.

Différencier : - éditorial : peut être évocateur ; - commerce : précis
; - transaction : extrêmement clair ; - SAV : humain, concret, utile.

------------------------------------------------------------------------

# 24. Espace et respiration

L'espace vide est un élément actif du branding.

Ne pas remplir une zone uniquement parce qu'elle est disponible.

Laisser : - le produit respirer ; - les images exister ; - les titres
avoir de l'importance ; - le client comprendre avant de solliciter une
nouvelle action.

------------------------------------------------------------------------

# 25. Mobile

L'identité doit survivre à la simplification.

Sur mobile : - conserver les signatures essentielles ; - réduire les
effets secondaires ; - maintenir lisibilité et vitesse ; - concevoir les
interactions tactiles ; - éviter la miniaturisation du desktop.

------------------------------------------------------------------------

# 26. Accessibilité

L'identité ORAA ne doit pas dépendre : - d'une faible différence de
couleur ; - d'un hover ; - d'une animation ; - d'un son ; - d'une police
difficile à lire.

Prévoir contraste, focus, clavier, labels, reduced motion, sémantique et
zones tactiles.

------------------------------------------------------------------------

# 27. Design tokens

Claude Code devra centraliser, après validation finale : - couleurs ; -
typographies ; - échelle de tailles ; - espacements ; - rayons ; -
bordures ; - ombres ; - couches ; - durées ; - easings ; - focus ; -
largeurs de contenu ; - breakpoints pertinents.

Les valeurs définitives ne doivent pas être inventées avant validation
des choix encore ouverts.

------------------------------------------------------------------------

# 28. Composants

Bibliothèque commune attendue : - header/navigation ; - recherche ; -
boutons ; - liens ; - badges ; - cartes produit ; - prix ; - avis ; -
médias ; - accordéons ; - formulaires ; - sélecteurs ; - alertes ; -
panier ; - breadcrumbs si retenus ; - blocs éditoriaux ; - vidéo ; -
navigation de maison.

Chaque composant doit documenter ses états.

------------------------------------------------------------------------

# 29. Administration Shopify

Le système de marque doit être robuste aux changements de contenu.

Utiliser sections/blocks/metafields/metaobjects/sources dynamiques selon
pertinence.

Les éditeurs Shopify ne doivent pas pouvoir accidentellement créer une
page totalement hors marque sans garde-fous raisonnables.

------------------------------------------------------------------------

# 30. Gouvernance

Claude Code implémente le système ; il n'en devient pas directeur
artistique.

Sans validation humaine, ne pas : - changer le logo/anneau ; - fixer une
nouvelle palette maîtresse ; - choisir définitivement une typo non
validée ; - renommer les collections ; - inventer un nouveau langage
d'animation ; - modifier les règles commerciales ; - ajouter des dark
patterns ; - surcharger le Monde ; - déployer en production.

------------------------------------------------------------------------

# 31. Contrôle de cohérence

Pour chaque nouvelle page, vérifier :

### Reconnaissance

Peut-on reconnaître ORAA même sans grand logo ?

### Confiance

La page semble-t-elle sérieuse, cohérente et fiable ?

### Fonction

Le client comprend-il quoi faire ?

### Respiration

Y a-t-il assez d'espace ?

### Intensité

Sommes-nous au bon niveau : Monde, maison, produit ou transaction ?

### Mobile

La marque reste-t-elle forte sans les effets desktop ?

### Accessibilité

La fonction reste-t-elle disponible sans animation/hover ?

------------------------------------------------------------------------

# 32. Definition of Done --- Brand System

Le Brand System est prêt pour gel V1 lorsque : - anneau de référence
documenté ; - palette exacte validée ; - typographies exactes validées
; - hiérarchie typographique validée ; - règles photo/vidéo validées ; -
motion system validé ; - tokens définis ; - composants principaux
définis ; - états interactifs définis ; - Monde et maisons compatibles
; - produit/panier/checkout cohérents ; - e-mails/post-achat cohérents
; - mobile testé ; - accessibilité testée ; - aucune rupture majeure de
marque sur le parcours complet.

------------------------------------------------------------------------

# 33. Critère ultime

Le client peut passer :

**du ciel du Monde ORAA → à une maison → à un produit → au panier → au
paiement → à l'e-mail de confirmation**

sans jamais se demander inconsciemment :

**« Est-ce que je suis encore chez la même marque ? »**

Et malgré cette cohérence, il ne doit jamais ressentir que ORAA lui
prend tout l'espace.
